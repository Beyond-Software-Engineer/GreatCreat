# RuoYi-Vue 项目技术文档

## 1. 项目概述

RuoYi-Vue 是一套基于 Spring Boot 3 和 Vue 3 的前后端分离的 Java 快速开发框架，提供了完整的权限管理、系统监控、代码生成等功能，可用于快速构建企业级管理系统。

- **版本**：3.9.2
- **定位**：企业级管理系统快速开发框架
- **特点**：开箱即用、功能完整、易于扩展

## 4. 核心功能模块

### 4.1 系统管理
- **用户管理**：用户信息的增删改查、角色分配、密码重置
- **部门管理**：组织机构管理，支持树结构展示，实现数据权限控制
- **岗位管理**：岗位信息管理，用于用户职位分配
- **菜单管理**：菜单配置、权限控制、按钮权限标识
- **角色管理**：角色菜单权限分配、数据范围权限设置
- **字典管理**：系统常用固定数据的维护
- **配置管理**：系统动态参数配置
- **通知公告**：系统通知信息发布维护

### 4.2 监控管理
- **操作日志**：系统操作行为记录和查询
- **登录日志**：用户登录信息记录和异常查询
- **在线用户**：当前系统活跃用户状态监控
- **服务器监控**：CPU、内存、磁盘、堆栈等系统信息监控
- **缓存监控**：Redis 缓存信息查询和命令统计
- **连接池监视**：数据库连接池状态监控，SQL 分析

### 4.3 工具管理
- **代码生成**：前后端代码自动生成，支持 CRUD 操作
- **表单构建**：可视化表单设计，生成 HTML 代码
- **系统接口**：自动生成 API 接口文档

## 5. 系统架构

### 5.1 后端架构
- **三层架构**：Controller → Service → Dao
- **权限控制**：基于 RBAC 模型，使用 JWT 进行无状态认证
- **安全机制**：XSS 防护、CSRF 防护、请求限流、防止重复提交
- **数据源**：支持多数据源切换，使用 Druid 连接池
- **事务管理**：声明式事务，保证数据一致性
- **缓存策略**：使用 Redis 缓存热点数据，提高系统性能

**重要说明**：框架层（ruoyi-framework）是系统的核心基础，包含安全认证、数据源配置、拦截器等核心功能，**禁止修改**框架层代码，以保证系统的稳定性和安全性。

### 5.2 前端架构
- **组件化设计**：高度组件化，提高代码复用性
- **路由管理**：动态路由生成，基于权限控制
- **状态管理**：使用 Pinia 进行集中状态管理
- **API 封装**：统一的请求处理，包括错误处理和拦截器
- **权限控制**：前端路由权限控制，按钮权限控制
- **响应式布局**：适配不同屏幕尺寸

## 7. 部署说明

### 7.1 后端部署
1. **环境准备**：JDK 17+、Maven 3.6+、MySQL 5.7+、Redis 5.0+
2. **数据库配置**：创建数据库并导入初始化 SQL
3. **修改配置**：调整 application.yml 中的数据库连接信息
4. **构建项目**：执行 `mvn clean package` 生成 jar 包
5. **启动服务**：执行 `java -jar ruoyi-admin.jar` 启动应用

### 7.2 前端部署
1. **环境准备**：Node.js 14+、npm 6+
2. **安装依赖**：执行 `npm install` 安装依赖
3. **构建项目**：执行 `npm run build:prod` 生成静态资源
4. **部署资源**：将 dist 目录部署到 Nginx 或其他静态资源服务器
5. **配置代理**：在 Nginx 中配置反向代理，指向后端服务

## 8. 安全特性

### 8.1 认证授权
- **JWT 认证**：无状态认证，支持多终端
- **密码加密**：使用 BCrypt 进行密码加密存储
- **登录限制**：密码错误次数限制，超过限制锁定账号

### 8.2 权限控制
- **基于角色的权限控制**：不同角色拥有不同权限
- **数据范围权限**：基于部门的数据访问控制
- **按钮权限控制**：细粒度的操作权限控制

### 8.3 安全防护
- **XSS 防护**：请求参数过滤，防止跨站脚本攻击
- **CSRF 防护**：Token 验证，防止跨站请求伪造
- **SQL 注入防护**：使用 MyBatis 预处理语句
- **防止重复提交**：请求拦截，防止表单重复提交
- **接口限流**：防止恶意请求导致系统过载
- **防盗链**：资源访问控制，防止非法引用

## 9. 开发指南

### 9.1 后端开发
1. **代码生成**：使用内置代码生成器生成基础代码
2. **遵循规范**：按照三层架构组织代码
3. **异常处理**：使用统一的异常处理机制
4. **日志记录**：使用 @Log 注解记录操作日志
5. **权限控制**：使用 @PreAuthorize 注解进行权限控制

### 9.2 前端开发
1. **组件开发**：遵循 Vue 3 组件开发规范
2. **API 调用**：使用封装的 request 工具进行接口调用
3. **状态管理**：使用 Pinia 进行状态管理
4. **路由配置**：在 router/index.js 中配置路由
5. **权限控制**：使用指令进行按钮权限控制

4. **多环境配置**：支持开发、测试、生产多环境配置

## 13. 总结

RuoYi-Vue 是一个功能完整、架构清晰、安全可靠的企业级管理系统框架，具有以下优势：
